## Русский

### Мегаструктуры: прогулки от первого лица по гигантским сооружениям (Unity)

Из ролика **«Мегаструктуры»**: атмосферные прогулки на Unity — вниз по бруталистской шахте Abyss, по внутренней стороне кольцевого мира The Ring, вверх по космическому лифту Thread и вдоль гигантской морской дамбы Bulwark. Использованные модели ИИ указаны в таблице. Геометрия, шейдеры, текстуры и звук преимущественно созданы кодом; сторонние ресурсы перечислены в документации игр.

### Быстрый старт

- **Bulwark:** скачайте один `Bulwark-Windows-x64.exe` по ссылке в таблице и дважды кликните по нему. Распаковка и установка не нужны.
- **Abyss, The Ring и Thread:** нажмите «⬇ Windows», распакуйте ZIP и запустите `.exe` внутри.
- **macOS:** для некоторых игр есть сборка «⬇ macOS» (см. HOW_TO_PLAY).
- Подробный гайд по запуску и по открытию исходников в движке: **[HOW_TO_PLAY.md](HOW_TO_PLAY.md#русский)**

## English

### Megastructures: first-person walks through colossal structures (Unity)

From the **Megastructures** video: atmospheric Unity walks — down the brutalist shaft Abyss, across the inside of the ringworld The Ring, up the space elevator Thread, and along the colossal sea dam Bulwark. The AI models used are listed in the table. Geometry, shaders, textures, and sound are primarily generated by code; third-party assets are documented in each game.

### Quick start

- **Bulwark:** download the single `Bulwark-Windows-x64.exe` from the table and double-click it. No manual extraction or installation is needed.
- **Abyss, The Ring, and Thread:** click “⬇ Windows”, unzip the archive, and run the `.exe` inside.
- **macOS:** some games also have a “⬇ macOS” build (see HOW_TO_PLAY).
- Detailed run guide and how to open the sources in the engine: **[HOW_TO_PLAY.md](HOW_TO_PLAY.md#english)**
