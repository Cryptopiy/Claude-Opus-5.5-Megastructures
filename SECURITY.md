# Security policy / Политика безопасности

**[Русский](#русский) · [English](#english)**

---

## Русский

### Поддерживаемые версии

Актуальная ветка `main` и последний опубликованный релиз. Старые коммиты и релизы могут не получать исправления.

### Как сообщить об уязвимости

Используйте приватный GitHub Security Advisory:
https://github.com/Cryptopiy/Claude-Opus-5.5-Megastructures/security/advisories/new

Если приватный канал недоступен, откройте общий Issue без технических деталей эксплуатации и попросите приватный способ связи. Не публикуйте уязвимость «нулевого дня», секреты, токены или персональные данные в публичном Issue.

Укажите, если возможно:

- затронутую игру, файл, коммит или релиз;
- шаги воспроизведения и ожидаемый/фактический результат;
- влияние на запуск проекта, обработку ассетов, выполнение скриптов или данные пользователя;
- минимальный пример без вредоносной полезной нагрузки.

Ответ и исправление выполняются по возможности; гарантированный срок не обещается. Уязвимости самой Unity, Python, FFmpeg или других внешних компонентов следует также сообщить их разработчикам.

## English

### Supported versions

The current `main` branch and the latest published release. Older commits and releases may not receive fixes.

### Reporting a vulnerability

Use a private GitHub Security Advisory:
https://github.com/Cryptopiy/Claude-Opus-5.5-Megastructures/security/advisories/new

If the private channel is unavailable, open a general Issue without exploitation details and ask for a private contact method. Do not publish a zero-day vulnerability, secrets, tokens or personal data in a public Issue.

When possible, include:

- the affected game, file, commit or release;
- reproduction steps and expected/actual behaviour;
- impact on project execution, asset handling, scripts or user data;
- a minimal example without a malicious payload.

Responses and fixes are provided on a best-effort basis; no response-time guarantee is made. Vulnerabilities in Unity, Python, FFmpeg or other external components should also be reported to their respective developers.
