# Support / Поддержка

## Русский

- Запуск и установка: [HOW_TO_PLAY.md](HOW_TO_PLAY.md).
- Состав и лицензии: [README.md](README.md), [NOTICE.md](NOTICE.md), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- Ошибка в игре или документации: создайте Issue и выберите шаблон. Укажите игру, коммит/релиз, ОС, версию Unity и шаги воспроизведения.
- Предложение изменения: [CONTRIBUTING.md](CONTRIBUTING.md).
- Уязвимость или утечка секрета: только приватно по [SECURITY.md](SECURITY.md).

Поддержка осуществляется по возможности. Не публикуйте токены, личные пути, персональные данные или большие логи без необходимости.

## English

- Installation and running: [HOW_TO_PLAY.md](HOW_TO_PLAY.md).
- Contents and licensing: [README.md](README.md), [NOTICE.md](NOTICE.md), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- Game or documentation bug: open an Issue using the appropriate template. Include the game, commit/release, OS, Unity version and reproduction steps.
- Proposing a change: [CONTRIBUTING.md](CONTRIBUTING.md).
- Vulnerability or leaked secret: report privately using [SECURITY.md](SECURITY.md).

Support is provided on a best-effort basis. Do not post tokens, personal paths, personal data or unnecessarily large logs.
