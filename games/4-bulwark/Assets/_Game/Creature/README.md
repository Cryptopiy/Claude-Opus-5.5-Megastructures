# The kraken (Addendum A1 1.1-1.5, lead decisions A1 00; owner: kraken builder)

What is here, how it is made, and the PUBLIC API the choreography (`KrakenDirector*`, show builder), the window-gallery
encounter (gallery builder) and the QA rig use. The API below is a compatibility contract: members are only ever added.

## Frame of reference and scale
Kraken local space: metres, origin at the arm crown, +Y up through the head, +Z the face side (`MODEL_SCALE` 220 m per glTF
unit). Head + mantle 331 m long, 210 m tall above the crown; main eyeballs 20 m (radius 10) at local (+-43, 66, -47), lesser
eyes 8, 6 (milky, never glows), 4 m per side above-behind them. Arms: 1300 m from the crown centre (`KrakenRig.ArmLength`),
24 m thick at the cut (u 286 m), A1 1.2 power-law taper to a 0.6 m whip. `rig.Scale` multiplies everything (1 = the A1 size).

## Public API (backward compatible: only additions)
```csharp
// once, behind the load fade (IBeatBuilder.Build)
KrakenCreature kc = KrakenCreature.Build(ctx, parentTransform);   // kc.Rig == null when the assets / shaders failed ([BW-FAIL] logged)
// per frame (IWorldUpdater.OnFrame), in this order
KrakenRig rig = kc.Rig;
rig.ResetInputs();                                    // optional: back to Lurk 1, no masks, no reach, curl/twist 0, agitation 1
rig.SetRoot(worldPos, headingDeg, pitchDeg, rollDeg); // the arm crown; heading 0 = face north (+Z), 90 = east
rig.SetPresetWeight(KrakenPreset.Swim, w);            // Lurk, Swim, Breach, ReachUp, Slap, GlideAlong, Withdraw (rest -> Lurk)
rig.SetLimbMask(KrakenPreset.ReachUp, limb, w);       // which arms the masked presets move (ReachUp, Slap, GlideAlong)
rig.SetReachHeight(m); rig.SetSlapHeight(m); rig.SetSlapPhase(limb, 0..1);
rig.SetReach(limb, worldTarget, weight, effectorU);   // steer an arm towards a point up to arc effectorU
rig.SetGlidePlane(worldPoint, normalTowardsKraken, slideDir);
rig.SetTwist(limb, deg); rig.SetCurl(limb, 0..1); rig.SetAutoCurl(0..1); rig.SetAgitation(0..3); rig.SetWetness(limb, 0..1);
rig.Current = worldDir;                               // the current the kelp streams in
rig.Evaluate(f.ambientTime);                          // pure function of the inputs and the UNWRAPPED ambient clock (double)
kc.HeadWetness = 0..1;                                // water sheets on the emerged head
kc.SetPupil(eye, 0 slit .. 1 round); kc.SetBlink(eye, closed01 or -1 = automatic);
kc.Sync(f.cameraPos, f.fovV, f.renderHeight, f.ambientTime, lookTarget, lookWeight, f.capture, dt);
int n = rig.CollectSeaDisturbances(seaY, bodyVelocity, kc.HeadLocal, buffer);   // then SeaDisturbances.Begin/Set/Publish
// underwater rendering (the gallery / window portal): global for all creature shaders
KrakenCreature.SetUnderwater(weight01, seaSurfaceY, emissionKeep01, airPathMetres);
```
Eye helpers (added Wave X): `kc.EyeIndex("main_r")`; `kc.HeadingFacingEye(eye, rootWorld, cameraPos)` (or the static
`KrakenCreature.HeadingFacingEye(manifest, "main_r", rootWorld, cameraPos)`) returns the heading that turns that eye's deep
socket to the camera. The sockets look SIDEWAYS (main eyes at local x +-43 m, normals 62 deg off the face): with the face
towards the walker both eyes hide in their sockets; turn the head so ONE eye stares (A1 1.1 rule 7).
Sea disturbances: `CollectSeaDisturbances(seaY, bodyVelocity, ...)` makes the Breach spray follow the RISE speed
(`bodyVelocity.y`, full at 3 m/s; a head standing still keeps a 0.15 foam collar), and a TentacleRise publishes only the
height of the emerged arc that stays inside the mist owner's vertical sheath (<= 60 m), so arching arms carry no 300 m
columns of falling water. Pass the real root velocity (m/s).

Read-only outputs: `rig.LocalToWorld` / `WorldToLocal`, `rig.Limbs[k]` (`CurP`, `U`, `Radius`, `Length`, `U0`, `RadiusAt(u)`,
`CurrentAt(u)`), `rig.LimbPointWorld(limb, u)`, `rig.LimbBoundsWorld(limb, u0, u1)`, `rig.MantleContraction`,
`rig.Breathing`, `kc.EyeWorld(i)`, `kc.EyeCount`, `kc.HeadLocal`, `kc.Root`, `kc.Triangles`. QA: `kc.ForceLod`, `kc.Visible`.
Constants: `KrakenRig.ArmCount` 8, `LimbCount` 10 (8, 9 = feeding tentacles, hidden: `Limbs[k].Visible`), `ControlPoints` 96,
`ArmLength` 1300, `MaxVisibleSpeed` 8 m/s, `KrakenCreature.BodyLodPx`, `TubeLodPx`.

Eyes: `lookWeight` 1 = every eye turns to `lookTarget` (pass the camera: it watches you) at most `EyeMaxRate` 10 deg/s with
`EyeLatency` 1.5 s (A1 1.1 rule 7); in capture stills (`capture = true`) they snap. Eye order = `Assets.Manifest.eyes`
(`main_r`, `main_l`, then the lesser eyes `l8_*`, `l6milky_*`, `l4_*`).

## LOD, shadows and cost (measured, Wave X build kraken-build16, RTX 5070, 3840 x 2160, -perf-rt, uncapped)
- Body LODs 330k / 80k / 20k / 4k by the projected head radius (`BodyLodPx` 420 / 130 / 36 px), tubes 3 LODs by the nearest
  point's projected radius (`TubeLodPx` 36 / 2.5 px), each switch a complementary blue-noise cross-fade over x0.8..x1.25.
  `kr_seq_dolly` (250 -> 2400 m in 20 s) has 0 difference spikes (`QA/reports/sequences_kraken12s.md`).
- Shadow proxy: while the finest LOD is shown alone, the next LOD casts its shadow (ShadowsOnly); kelp and eyes cast none.
- GPU cost (kraken on minus `-kraken-off`, median): crest view `crestnear` (two arms 60-120 m away) +1.21 ms; worst case
  `eyeair` (the head fills the frame 90 m away) +1.82 ms. After the Wave X resume skin changes (build kraken-build34,
  `QA/perf/kraken34_*.csv`; another builder's player was running): `eyeair` +1.67 ms, `crestnear` +1.18 ms, `head600`
  +0.82 ms. The skin's noises use `KrHash3` (one PCG round per lattice point) and skip faded octaves (`KrFbm`,
  `KrFbmGrad`, `KrFbmCrease` in BwCreatureSkin.hlsl); BwGradNoise3's table lookup compiled to an indexable temp (+1 ms). Triangles per frame (all passes) 1.74M / 1.32M with the kraken
  (QA/perf/kraken16_*.csv). The arm-to-tile blend samples the tile only where it is active (explicit gradients) and the
  barnacle Worley uses the nearest-octant 8 cells (exact for the shells).

## Skin shading notes (Wave X resume, builds kraken-build19..)
- Both normal maps are BC5 on Standalone (R x, G y, B 0): `KrUnpack` takes x = r a (also reads DXT5nm / RGB) and rebuilds
  z. Before, B was read as z (-1, clamped 0.05): every baked slope was tilted ~20x (median 3 deg -> 45 deg) and the hide
  read as rippled glass at every distance. `_NormalStrength` default 2.2 (x0.6 from ~0.6 m per pixel).
- Rock-like wet hide: a 3 m creased (wrinkle) gradient-noise bump on the whole hide (not the sucker cups) and an 11 m lumpy
  relief on the head (both rest space, footprint-filtered, faded at grazing angles); water sheets smoothness 0.72 (was 0.84); dome x0.74;
  grazing micro-shadowing (x0.70 at N.V < 0.05); footprint roughening (x0.78 from ~0.7 m per pixel); a Kaplanyan specular AA
  on the final normal (kernel roughness^2 <= 0.36); hooks shown from ~5 px per hook.
- Relief tube (LOD0) cross-fade: while it fades out (`_KrFade.z` = LOD index 0, mode 0, coverage < 1) its relief normals morph
  to the smooth radial normal and its relief displacement folds back to the smooth radius (vertex colour w) by mid-band, so the
  dithered mix with the smooth LOD1 has one silhouette and one shading; inside every band the smoothness dips to x0.8; the
  red thin-part scattering is confined to the arm undersides (backs keep 30 %).
- The white veil over the head in the show's K4/K5 noon shots is the mist's Breach spray (the director's head Breach at
  strength >= 0.25 while the head stands), not the skin: compare `QA/captures/kraken-show19/show_k5_ks11.png` with
  `kraken-show19n` (same build, `-sea-dist-qa near`, no kraken spray). The rig's own `CollectSeaDisturbances` keeps a 0.15
  collar for a standing head.

## Eye (A1 1.2, with the Wave X readability changes)
Eyeball 20 m; iris 9.6 m (`_IrisRadius` 0.50 rad: the carved socket shows only +-0.55 R vertically, so A1's 12 m iris read as
a band, "lips"); horizontal bar pupil 6.6 x 1.5 m, level in the world; hooded almond lids; emission E 5.5 in air (A1 4.0) and
6.0 under water, clamped to 3.0 AFTER exposure (`_KrPhase.w` = 3 / 2^EV from `GradeState.ExposureEV`).

## Rules for the drivers (lead decision 2: slow and heavy, visible parts <= 8 m/s)
- At CONSTANT preset weights every preset stays under 8 m/s anywhere on the animal (measured: `KrakenTests.
  Rig_IsDeterministicContinuousAndSlow`, log lines `[BW] kraken motion ...`). Changing inputs adds speed: ease every
  weight, mask, reach, curl and twist with `KrakenRig.Ease` (smootherstep) over >= 20 s (a full ReachUp >= 40 s; a
  Slap phase 0 -> 1 over >= 45 s; SetCurl over >= 30 s; SetTwist over >= 10 s); move the root at <= 8 m/s near the
  surface (A1 1.4 deep transit up to 25 m/s only with the body top >= 40 m deep), heading at <= 1.5 deg/s.
- One kraken at a time: the skinning buffer and limb tables are shader globals. `KrakenCreature.Exclusive` (QA rig) hides
  every other instance.
- LOD: a pure function of the camera (projected head / tube radius) with a dithered complementary cross-fade over
  x0.8 .. x1.25 of each threshold: no pop, reproducible in captures.
- Captures: everything is a pure function of (inputs, ambient clock): pass the shot's ambient time.
