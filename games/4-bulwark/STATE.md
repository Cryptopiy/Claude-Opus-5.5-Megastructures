## Commands
All from the project root in PowerShell (`Set-Location "<WORKSPACE>\4 Megastructures\4 Megastructures"`); the path has spaces, so call the scripts with `powershell -NoProfile -ExecutionPolicy Bypass -File ...` from a session, not through `Start-Process -ArgumentList` (it splits quoted paths). Long jobs: detach with the tool's background mode and a log, or `Start-Process ... -RedirectStandardOutput Logs\<x>.out` when no argument contains a space. Details: docs/FRAMEWORK.md section 5.
- Fast type check (15 s): `python -I Tools/fastcompile.py all` -> Runtime, RuntimeEd, Editor, Tests, PlayTests OK. HLSL twins: `python -I Tools/gen_hlsl.py --check`.
- Unity compile (one Unity at a time, always through the queue; ~30-80 s): `powershell -NoProfile -ExecutionPolicy Bypass -File Tools\unity-queue.ps1 -Name compile -Method Megastructure.EditorTools.BatchTools.CompileCheck`
- Regenerate everything (settings, HLSL, materials, Main.unity; idempotent): `... Tools\unity-queue.ps1 -Name rebuild -Method Megastructure.EditorTools.BatchTools.RebuildAll -TimeoutMin 30`
- Validate (51 rows): `... Tools\unity-queue.ps1 -Name validate -Method Megastructure.EditorTools.BatchTools.Validate`
- Build (~30-100 s): `... Tools\unity-queue.ps1 -Name build -Method Megastructure.EditorTools.BatchTools.BuildWindows` -> `Builds\Bulwark\Bulwark.exe` (`-BuildDir Builds\<owner>` for a per-owner folder)
- EditMode tests: `$res = (Resolve-Path QA\tests).Path + "\editmode.xml"; powershell -NoProfile -ExecutionPolicy Bypass -File Tools\unity-queue.ps1 -Name tests -NoQuit -ExtraArgs "-runTests,-testPlatform,EditMode,-testResults,$res"` (PlayMode: `-testPlatform,PlayMode`, `playmode.xml`)
- GPU state before any long job: `powershell -NoProfile -ExecutionPolicy Bypass -File Tools\gpu-guard.ps1 -Status`
